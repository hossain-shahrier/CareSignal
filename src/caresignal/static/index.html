Input features (7)

    End-to-end flow

    1. FHIR bundles — Synthea (or compatible) JSON per patient with Patient, Encounter, Condition, Procedure resources.
    2. Feature pipeline — Each finished inpatient discharge becomes one row; label = readmit within 30 days if a new inpatient stay starts in window.
    3. Model — LightGBM with calibration; threshold tuned on validation for F1.
    4. API — This UI and /predict consume the same feature schema as training.

    Understanding the score

    Risk score is a calibrated probability (0–100%) of at least one inpatient readmission within 30 days after the index discharge.

    Predicted readmission applies the tuned decision threshold: scores at or above the threshold are flagged as elevated risk.

    Important limitations

    • Demonstration / portfolio project — not FDA-cleared or validated for care.
    • Trained on synthetic Synthea populations; retrain before any real deployment.
    • Does not use medications, labs, vitals, or social determinants in this version.
